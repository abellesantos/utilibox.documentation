# Emissions Explorer

This tab provides a detailed view of emissions data across all sites within the organization. It allows users to analyze emissions performance based on **actual data** or **scenario-based projections**.

* Displays emissions for the **current calendar year**
* Supports both **actual data (default)** and **scenario-driven data**
* Enables filtering at a **utility identifier level**.

#### **Common Usage Scenarios**

**A. Actual Emissions Review**

* Use default view
* Validate emissions across all sites

**B. Forecast Validation**

* Apply a scenario
* Review projected emissions based on growth/reduction assumptions

**C. Site-Level Investigation**

* Filter by meter identifier
* Analyze emissions for a specific site
