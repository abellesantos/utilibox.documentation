# Getting Started

When you open Utilibox AI, you'll be greeted with a message inviting you to ask questions about your energy portfolio.

Simply type your question into the message field and press **Enter** to begin.

Examples include:

* Are any contracts expiring soon?
* Break down my electricity spend by site for the last quarter.
* Which sites have the highest overdue amounts?
* How has electricity spend changed month by month?
* Are there any unusual changes in energy usage or cost?
* Summarize the key portfolio issues that need attention.

These example prompts are included within the Utilibox AI experience to help users get started quickly.
